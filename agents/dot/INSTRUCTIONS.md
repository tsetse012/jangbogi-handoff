# dot 지시서

너는 수빈의 dot이다. 이 저장소의 명세서대로 쿠팡 장바구니에 상품을 담는다. 이번 실험(EXP-02)의 목적은 「dot의 클라우드 브라우저가 한국 쇼핑몰에서 명세서를 정확히 담는가」를 재는 것이다. 못 하는 단계가 있어도 거기까지를 정확히 보고하면 성공이다.

## 절차
1. 저장소를 받는다: `git clone https://github.com/tsetse012/jangbogi-handoff` (GitHub 플러그인이 있으면 그걸로 읽어도 된다).
2. [AGENTS.md](../../AGENTS.md)를 읽는다.
3. 명세서 `manifests/2026-W44/coupang.md`를 연다.
4. 자기 브라우저로 coupang.com에 들어간다. 로그인은 **Passwords에 저장된 쿠팡 로그인**으로. 없으면 수빈에게 「쿠팡 로그인을 Passwords에 저장해 달라」고 요청하고 멈춘다. 채팅으로 받은 비밀번호는 쓰지 않는다.
5. 명세서 표를 위에서부터 한 행씩 담는다(링크 행은 링크, 검색어 행은 「상품 조건」에 맞는 가장 싼 로켓프레시/로켓배송 상품).
6. 품절·가격 초과는 「품절 시」 열대로. 비어 있으면 담지 않는다.
7. 장바구니 화면에서 담긴 상품명·수량·단가·합계를 읽고 `results/TEMPLATE.md` 형식으로 보고한다. 첫 줄 `결과: 완료|부분|중단`. GitHub 플러그인으로 저장소에 Issue를 만들 수 있으면 제목 `EXP-02 dot <날짜>`로 올리고, 안 되면 채팅에만 쓴다.
8. **결제하지 않는다.** 「구매하기」 화면에서 멈춘다.

## 꼭 적을 것 (실험 지표)
- 쿠팡 접속이 됐는가(차단·CAPTCHA·보안 프로그램 요구 여부)
- 로그인 경로(Passwords / 사람 개입 / 실패)
- 품목별: 담김 여부, 담긴 상품명, 수량, 단가, 명세서와 다른 점
- 사람 개입이 필요했던 횟수와 단계
- 걸린 시간

- 저장소 파일 수정·삭제(Issue만 가능).
