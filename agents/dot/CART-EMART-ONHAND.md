# dot 지시서 — 이마트몰 담기 + 남은 재료 왕복 (EXP-05)

너는 수빈의 dot이다. 이번 실험은 두 가지를 잰다.
- **A. 담기·금액 읽기** — 우리 엔진이 계산한 실결제 예상 금액이 이마트몰(SSG닷컴) 장바구니 화면 금액과 같은가.
- **B. 남은 재료 왕복** — 명세서 끝 「다음 주 요청서에 붙일 재고」 블록을 네가 보관했다가, 다음 주에 수빈에게 **실제로 남은 양을 물어** 다음 주 요청서의 `on_hand` 로 만들 수 있는가.

## A. 담기 (명세서 = `manifests/2026-W46/emart.md`)
1. [AGENTS.md](../../AGENTS.md) 공통 규칙 1~4·6을 읽는다(알레르기 절은 안 읽어도 된다). 「예상(엔진 추정)」 절은 **보고 전까지 읽지 않는다**.
2. 네 브라우저로 emart.ssg.com 에 들어간다. 로그인 화면이 나오면 **「보안 입력 요청」을 보내 수빈이 직접 넣게 한다**. 채팅으로 받은 비밀번호는 쓰지 않는다. 멤버십 확인은 필요 없다(일반 회원 상품만).
3. **담기 전에 장바구니를 먼저 연다.** 이미 있는 상품은 **지우지 말고** 상품명·수량·금액을 「기존 상품」으로 적는다. 명세서 6품목 중 이미 담긴 것이 있으면 수량을 늘리지 말고 그 사실만 적는다.
4. 표 6행을 위에서부터 한 행씩: 링크를 연다(🔴 SSG닷컴은 링크를 바로 열면 「올바르지 않은 접근 경로입니다」로 메인에 튕길 수 있다 → 상단 검색창에 상품명을 넣어 **같은 상품(이름·규격·쓱배송)** 을 찾는다) → 판매가·할인가·배송 방식을 읽고 → 수량 1로 담는다.
5. 품절·가격 상한 초과는 「품절 시」 열대로. 「대체 규칙 미정」이면 담지 않고 보고에 적는다.
6. 장바구니 화면을 **보이는 그대로** 읽는다: 품목별 상품명·수량·금액 · 금액 요약 칸의 **모든 줄**(이름 그대로) · 배송 안내 문구 원문 한 줄 · 「N원 더 담으면 무료배송」 안내 원문. 기존 상품이 있으면 금액 요약이 그것까지 합친 값인지 적고, 체크박스로 우리 6품목만 고를 수 있으면 그 상태의 금액도 따로 읽는다(체크 해제는 OK, 삭제는 금지). 배송 시간대는 **고르지 않는다**.
7. **「주문하기」를 누르지 않는다.** 담은 상품은 그대로 둔다.

## B. 남은 재료 왕복
8. 명세서 맨 끝 「다음 주 요청서에 붙일 재고」 json 블록을 **그대로** 네 메모(또는 이 대화)에 보관한다. 값을 고치지 않는다.
9. 수빈이 「다음 주야」라고 하면(이번 실험에서는 같은 대화에서 바로 이어 말한다), 보관한 블록의 **재료마다 하나씩** 수빈에게 묻는다. 질문 형식: 「지난주 남은 감자 640g — 지금 얼마나 남았어요? (다 먹었으면 0)」. 재료 이름은 한글로, 숫자는 블록 값 그대로.
   - 답이 「반쯤」·「조금」처럼 숫자가 아니면 **추측하지 말고** g(또는 개)로 다시 묻는다.
   - 블록에 없는 재료를 수빈이 말하면(「양파도 있어」) 받지 말고 「이번 블록에 없는 재료라 넣지 않았어요」라고 적는다.
10. 답을 모으면 다음 주 요청서에 붙일 json 을 만든다: `{"on_hand": [{"key": ..., "qty": 정수, "unit": "g" 또는 "개"}]}`. key·unit 은 보관한 블록 그대로, qty 는 수빈이 답한 숫자. **0 인 재료는 빼라.** 모두 0 이면 `{"on_hand": []}`.

## 보고 (채팅)
A 가 끝나면 한 번, B 가 끝나면 한 번 보고한다.
- A 보고: 첫 줄 `결과: 완료|부분|중단 — 한 문장`. 본문은 [results/TEMPLATE.md](../../results/TEMPLATE.md) 표(명세서 경로만 바꿔서) + 6번 금액 요약 원문. 그다음 「예상(엔진 추정)」 절을 읽고 화면 결제예정금액과의 차이를 한 줄. 맨 끝 **json 코드블록 정확히 1개**:
```json
{
  "exp": "EXP-05",
  "mall": "emart",
  "manifest": "manifests/2026-W46/emart.md",
  "preexisting_items": [{"name": "", "qty": 0, "price": 0}],
  "rows": [{"row": 1, "added": true, "name_on_screen": "", "qty": 1, "list_price": 0, "sale_price": 0, "delivery": "", "note": ""}],
  "summary_lines": [{"label": "화면 이름 그대로", "amount": 0}],
  "summary_scope": "ours_only|includes_preexisting",
  "shipping_notice": "",
  "free_shipping_notice": "",
  "stopped_at": "",
  "kept_block": {"on_hand": []}
}
```
- B 보고: 질문과 답을 순서대로 적고, 맨 끝 **json 코드블록 정확히 1개** = 10번의 `{"on_hand": [...]}` 만.
- 금액은 원 단위 정수(콤마·「원」 빼고). 화면에 없는 값은 `null`. 추측해서 채우지 않는다.

## 멈출 때
- CAPTCHA·본인인증·주소 입력 요구 → 수빈에게 넘기고 어디서 멈췄는지 적는다. 같은 오류가 2번이면 그 행을 건너뛰고 사유를 쓴다.
