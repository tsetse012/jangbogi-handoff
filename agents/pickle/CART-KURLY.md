# 피클 지시서 — 컬리 장바구니 담기 (EXP-03 · 계산 총액 검증)

너는 수빈의 피클이다. 이 실험의 목적은 **우리 엔진이 계산한 실결제 예상 금액이 컬리 장바구니 화면의 금액과 같은지** 확인하는 것이다. 그래서 담는 것만큼 **장바구니 화면의 숫자를 그대로 읽어 오는 것**이 중요하다.

## 절차
1. [AGENTS.md](../../AGENTS.md)의 공통 규칙 1~4·6을 읽는다(알레르기 절은 이번엔 안 읽어도 된다).
2. 명세서 = `manifests/2026-W45/kurly.md`. 표 5행만 본다. 「예상(엔진 추정)」 절은 **보고 전까지 읽지 않는다**(화면 숫자를 거기에 맞추지 않게).
3. 컬리(kurly.com)에 **볼트에 저장된 로그인**으로 들어간다. 저장된 로그인이 없으면 「Sign in to 컬리」 카드를 보내 수빈이 볼트에 저장하게 한다. 채팅으로 비밀번호를 받지 않는다. 멤버십 확인은 필요 없다(일반 회원 상품만).
4. **담기 전에 장바구니를 먼저 연다.** 이미 담겨 있는 상품이 있으면 **지우지 말고** 상품명·수량·금액을 「기존 상품」으로 적어 둔다. 명세서 5품목 중 이미 담긴 것이 있으면 그 사실도 적는다(수량을 늘리지 말 것).
5. 표를 **위에서부터 한 행씩**: 링크를 열고 → 상품 페이지의 **판매가(할인 전)·할인가·배송 방식(샛별배송/택배 등)** 을 읽고 → 수량 1로 장바구니에 담는다. 옵션 선택 창이 뜨면 명세서 「상품 조건」과 같은 옵션만 고른다.
6. 품절·가격 상한 초과는 「품절 시」 열대로. 「대체 규칙 미정」이면 담지 않고 보고에 적는다.
7. 다 담으면 장바구니 화면을 열고 **화면에 보이는 그대로** 읽는다:
   - 품목별: 상품명 · 수량 · 표시 금액(할인 전/후 둘 다 보이면 둘 다)
   - 오른쪽(또는 아래) 금액 요약 칸의 **모든 줄**: 상품금액 · 상품할인금액 · 배송비 · 결제예정금액 등(이름도 화면 그대로)
   - 배송지와 「샛별배송 가능/택배 배송」 같은 배송 안내 문구 원문 한 줄
   - 「N원 더 담으면 무료배송」 같은 안내가 있으면 원문 그대로
   - 기존 상품이 있었다면, 금액 요약이 **기존 상품까지 합친 값인지** 적는다(체크박스로 우리 5품목만 고를 수 있으면 5품목만 체크한 상태의 금액 요약도 따로 읽는다 — 체크 해제는 해도 되고 삭제는 하지 않는다).
8. **「주문하기」 버튼은 누르지 않는다.** 결제·주문서 화면에 들어가지 않는다.
9. 담은 상품은 장바구니에 **그대로 둔다**(뺄지는 수빈이 정한다).

## 보고 (채팅)
첫 줄 `결과: 완료|부분|중단 — 한 문장`. 본문은 [results/TEMPLATE.md](../../results/TEMPLATE.md) 표 형식(명세서 경로만 바꿔서) + 7번에서 읽은 금액 요약 원문. 맨 끝에 **json 코드블록 정확히 1개**:

```json
{
  "exp": "EXP-03",
  "mall": "kurly",
  "manifest": "manifests/2026-W45/kurly.md",
  "preexisting_items": [{"name": "", "qty": 0, "price": 0}],
  "rows": [
    {"row": 1, "added": true, "name_on_screen": "", "qty": 1, "list_price": 0, "sale_price": 0, "delivery": "", "note": ""}
  ],
  "summary_lines": [{"label": "화면에 적힌 이름 그대로", "amount": 0}],
  "summary_scope": "five_only|includes_preexisting",
  "shipping_notice": "배송 안내 문구 원문",
  "free_shipping_notice": "",
  "stopped_at": ""
}
```
- 금액은 원 단위 정수(콤마·「원」 빼고). 화면에 없는 값은 `null`. 추측해서 채우지 않는다.
