# 피클 가격 조사 지시서 (담지 않음)

너는 수빈의 피클이다. 이번 과업은 담기가 아니라 **가격 조사**다.
장바구니 담기·결제·멤버십 가입은 하지 않는다. 상품명·가격·판매 단위만 가져온다.

## 왜 담지 않나
쿠팡 신선식품(로켓프레시)은 와우 회원 전용, 네이버 컬리N마트는 네이버플러스 회원 전용이라
멤버십 없는 계정에는 「장바구니 담기」가 없다(EXP-01 2026-10-27 실측 0/5). **멤버십이 없어도 상품 페이지와 가격은 보인다.**
그래서 이번엔 조회만 한다. **멤버십이 없어도 그대로 진행한다** — 가격만 보면 된다.

## 쇼핑몰별 표
수빈이 「컬리로」·「이마트몰로」처럼 쇼핑몰을 말한다. 말하지 않았으면 쿠팡. **한 번에 쇼핑몰 하나만** 조사한다.

| 쇼핑몰 | `mall` | 사이트 | 고르는 순서(배송 종류 → `delivery` 값) | 멤버십 전용이면 `membership_required` |
|---|---|---|---|---|
| 쿠팡 | `coupang` | coupang.com | 로켓프레시 `rocket_fresh` → 로켓배송 `rocket` → 판매자 배송 `seller` | 로켓와우 `"coupang_wow"` |
| 컬리 | `kurly` | kurly.com | 샛별배송 `dawn` → 하루배송 `next_day` → 판매자 배송(컬리 마켓플레이스) `seller` | (없음 — 컬리멤버스 전용 상품이면 본문에만 적고 `null`) |
| 이마트몰 | `emart` | emart.ssg.com (SSG닷컴의 「이마트몰」) | 쓱배송 `ssg_scheduled` → 2시간 배송 `two_hour` → 판매자 배송 `seller`(신세계몰·입점 판매자) | (없음 — `null`) |
| 네이버 | `naver` | 네이버플러스 스토어 「컬리N마트」 | 컬리N마트 상품 `kurly_n_mart` → 그 밖 네이버 판매자 `seller` | 컬리N마트 상품은 `"naver_plus"` |

- 같은 회사라도 **컬리(kurly.com)와 컬리N마트(네이버)는 다른 쇼핑몰**이다. 섞지 않는다.
- 이마트몰은 볼트 주소 기준으로 쓱배송·2시간 배송 가능 여부가 갈린다 — 상품 페이지에 뜨는 배송 종류를 그대로 적는다.
- 쇼핑몰마다 **배송비 안내 문구**(예: 「4만원 이상 무료배송」·「2만원 이상 주문 가능」)를 상품 페이지나 장바구니 안내에서 보면 본문 맨 위에 **원문 그대로 한 줄** 적는다(배송비 규칙 확인용 — 장바구니에 담지는 않는다).

## 절차
1. [AGENTS.md](../../AGENTS.md)를 읽는다(담기 금지·결제 금지 규칙은 여기서도 그대로 적용).
2. 수빈이 말한 조사 목록 파일(`manifests/pricecheck/…` 또는 주차 파일)을 연다.
   목록이 여럿이면 수빈이 말한 것만 연다(예: `manifests/pricecheck/2026-10-30-top50-a.md`).
   기본 예시 = `manifests/2026-W44/coupang.md` 표의 5행(담기용 명세서를 그대로 조사 목록으로 쓰는 경우).
3. 「쇼핑몰별 표」의 그 쇼핑몰 사이트를 연다. 로그인 없이 가격이 보이면 로그인하지 않아도 된다.
   로그인이 필요하면 **볼트에 저장된 로그인**으로, 없으면 「Sign in to <쇼핑몰>」 카드로 수빈에게 넘긴다.
   채팅으로 비밀번호를 받지 않는다.
4. 조사 목록을 **위에서부터 한 행씩**:
   - 상품 링크가 있으면 그 페이지를 연다(링크가 다른 쇼핑몰 것이면 무시하고 검색). 검색어만 있으면 검색해서
     「상품 조건」에 맞는 상품 중 **「쇼핑몰별 표」 고르는 순서의 앞쪽 배송 종류에서 가장 싼 것**을 하나 고른다.
   - 상품 페이지에서 **상품명(화면 그대로)·판매가·판매 단위·배송 종류·전용 여부·URL**을 읽는다.
   - 가격은 지금 결제되는 판매가의 **숫자만**(원). 할인 전 정가는 쓰지 않는다.
   - 로그인·멤버십 안내로 페이지가 가려져도 가격이 보이면 그대로 읽는다. 막히면 CAPTCHA·
     본인인증 화면에서 멈추고 「Open Browser」 카드로 수빈에게 넘긴다.
5. 목록의 행을 다 돌면 **채팅 보고 맨 끝에 ```json 코드블록 하나**를 붙인다.
   배열이고, 원소 하나 = 조사한 상품 하나. 코드블록은 **정확히 1개**여야 한다.
   한 행이 막히면(상품 없음·가격 안 보임) **그 행은 json 에서 빼고 본문에 이유를 적은 뒤 다음 행으로 넘어간다.**
   25행짜리 목록이면 시간이 길다 — 한 행에 오래 매달리지 않는다.

## 출력 형식 (그대로 쓴다)
```json
[
  {
    "ingredient_key": "egg",
    "mall": "coupang",
    "product_name": "곰곰 동물복지 무항생제 유정란 30구",
    "url": "https://www.coupang.com/vp/products/9128624486",
    "search_query": null,
    "pack_qty": 30,
    "pack_unit": "개",
    "price": 12760,
    "membership_required": "coupang_wow",
    "delivery": "rocket_fresh",
    "observed_at": "2026-10-27",
    "source": "PRICECHECK-2026-10-27"
  }
]
```

- `ingredient_key`: 조사 목록의 그 행이 가리키는 재료 키. **그 목록 파일에 있는 키만** 쓴다 —
  목록 밖의 키가 하나라도 오면 엔진이 결과 전체를 거부한다.
  (2026-W44 예시 = `egg`·`onion`·`tofu`·`zucchini`·`pork_shoulder` ·
  2026-10-30 예시 = `manifests/pricecheck/2026-10-30-top50-a.md`·`…-b.md` 의 25키씩.)
- `url`: 주소창의 상품 URL. 못 찾으면 `null` — 이때 `search_query`에 네가 쓴 검색어를 넣는다.
- `pack_qty`·`pack_unit`: **한 상품을 사면 실제로 몇 g/몇 개가 오는지**. 상품명의 판매 단위를
  총량으로 바꿔 적는다 — `30구` → `30`/`개` · `1.5kg` → `1500`/`g` · `300g 2개입` → `600`/`g`.
  **`pack_unit`은 `"g"` 또는 `"개"` 두 값만** 쓴다.
  🔴 **부피 상품(우유·생크림 등)** 은 상품 페이지에 **표시된 중량(g)** 만 쓴다. `ml`·`L` 표기만 있고 중량(g) 표기가 없으면 **그 행은 json 에서 빼고 본문에 『중량 표기 없음』이라고 적는다** (ml→g 환산은 엔진에 없다 — 추측해서 적으면 상한·단가가 틀어진다). `구`·`입`·`kg`을 쓰면 엔진이 결과 전체를 거부한다(2026-10-27 실측: `"구"` 1건으로 전체 반려).
- `price`: 그 한 팩의 판매가(원, 정수).
- `mall`: 「쇼핑몰별 표」의 `mall` 값. **보고 하나 = 쇼핑몰 하나**(엔진이 다른 쇼핑몰 값을 섞으면 거부한다).
- `membership_required`: 「쇼핑몰별 표」 마지막 열. 해당 없으면 `null`.
- `delivery`: 「쇼핑몰별 표」에서 **그 쇼핑몰의 값만**. 다른 쇼핑몰 값(예: 컬리 상품에 `rocket_fresh`)이나 표에 없는 값을 쓰면 엔진이 결과 전체를 거부한다.
- `observed_at`: 오늘 날짜 `YYYY-MM-DD`. `source`: `PRICECHECK-<오늘 날짜>`.

## 보고
- 본문은 짧게: 조사한 행 수, 각 행의 상품명·가격 한 줄, 못 찾은 행과 이유.
- 본문 다음에 json 코드블록. **표로 대신 적지 말고, 설명 문장 안에 섞지 마라.**
- 같은 상품을 두 번 넣지 않는다. 한 행에 상품 하나.

## 하지 말 것
- 장바구니 담기, 결제, 멤버십 가입, 쿠폰 적용, 주소 변경.
- 한 보고에 쇼핑몰 두 곳 섞기(쇼핑몰마다 따로 돌린다).
- 조사 목록에 없는 상품 조사(「더 싼 게 있다」는 발견은 본문에만 적는다).
- json 블록을 2개 이상 만들거나 0개로 끝내기 — 엔진이 실패로 멈춘다.
- 가격을 기억이나 추측으로 채우기. 못 본 행은 json에서 빼고 본문에 이유를 적는다
  (빠진 키는 엔진이 경고로 표시한다).
